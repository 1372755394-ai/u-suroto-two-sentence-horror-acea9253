The scariest horror story I can tell in exactly two sentences. A rescue dog, returned twice for barking at empty rooms, spends an hour barking at the bed its new owner is already lying in — the first sentence's "empty rooms" turn out not to have been empty at all, and the reader is left to fill in what shares the bed.

## Run it

```sh
python3 main.py
```

`main.py` uses only the Python standard library and writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The story is fixed text, so every run writes exactly the same file: deterministic, no network, no randomness.
